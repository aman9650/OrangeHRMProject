Loggin->
	Apache Log4j 2 is a widely used Java-based logging framework in test automation and 
	backend development. It replaces standard System.out.println() statements with structured, 
	timestamped logs routed to both the console and persistent log files.
	
Level Usage in Automation Logging
TRACE->Fine-grained, step-by-step element coordinates and raw HTTP payloads
DEBUG->Diagnostic details (e.g., extracted locator strings, dynamic wait timings)
INFO->High-level milestones (e.g., test started, browser launched, page loaded)
WARN->Non-breaking issues (e.g., deprecated method calls, slow response times)
ERROR->Assertion failures, missing elements, or runtime exceptions
FATAL->Critical aborts (e.g., environment down, database connection unavailable)
